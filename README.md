## 📌 Project Overview

Electricity billing systems often use **tiered slab rates**, fixed monthly service charges, and additional duty percentages depending on total bi-monthly consumption. Calculating these manually or through confusing government portals can be tedious.

This project provides an easy-to-use digital calculator that takes a user's unit consumption (kWh) and instantly outputs a **transparent, broken-down bill statement** showing exact costs per slab tier through a clean, modern interface styled with Tailwind CSS.

---

## ✨ Key Features

- **📊 Tiered Slab Calculation Engine:** Automatically breaks down total units across official tariff tiers (e.g., 0–100 free units, 101–200, 201–500, and 500+ units).
- **💵 Itemized Bill Breakdown:** Displays fixed charges, slab-wise energy charges, and applicable electricity duties separately.
- **🎨 Modern Tailwind UI:** Clean, responsive utility-first design optimized for seamless viewing across mobile, tablet, and desktop screens.
- **⚡ Fast Web Performance:** Zero external heavy framework dependencies for instant loading speeds.
